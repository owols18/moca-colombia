# Home en español

- Ruta: /es. La versión inglesa sigue en /en.
- Textos, títulos, CTA, descripciones de imágenes y etiquetas accesibles del slider: content/es/home.json.
- Las dos versiones usan HomeStory y las mismas escenas, imágenes, dimensiones y animaciones.
- Los enlaces del home español apuntan a /es; los enlaces del componente compartido de donación reciben el idioma automáticamente.
- No se cambiaron los valores de movimiento, posiciones ni capas aprobados.
- Única adaptación visual: el título «SOBRE NOSOTROS» reduce su tamaño en pantallas de hasta 380 px para evitar recortes. No afecta al inglés.
- Validación de contenido: node scripts/check-home-i18n.cjs.
